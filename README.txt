AMERICAN YOUTUBE — MONETIZATION CHECKER

Deploy the Node.js app to Render using the included render.yaml Blueprint. Upload all project files to a GitHub repository, create a new Blueprint in Render, connect the repository, add YOUTUBE_API_KEY as a secret environment variable, and deploy.

Run locally with Node.js 18+: npm start, then open http://localhost:10000.

Supported inputs include YouTube channel URLs (@handle, /channel/UC..., /c/name, /user/name) and video/Shorts URLs (resolved to the channel where possible).

The score is a heuristic index of public signals, not a verified YPP status or a statistical probability. YouTube does not expose a public API for another channel's monetization status or qualifying watch-hour/Shorts-view totals.
